# CoreFinder

Разработка и тестирование алгоритмов построения решения из C-ядра для кооперативной игры с трансферабельными выигрышами (ВКР).

Репозиторий содержит реализацию трёх алгоритмов построения предрешения, лежащего в C-ядре кооперативной игры (или близкого к нему, если ядро пусто), а также вспомогательные алгоритмы (вектор Шепли, N-ядро, точка ядра с минимальной суммой), генератор тестовых игр и инструменты для массового тестирования и сравнения алгоритмов.

## Быстрый старт

```python
from CoreFinder import CoreFinder

# Кооперативная игра трёх игроков
cf = CoreFinder(['1', '2', '3'], {
    '1': 0, '2': 0, '3': 0,
    '12': 10, '13': 20, '23': 30,
    '123': 50
})

print(cf.get_x())            # предрешение игры
print(cf.get_imputation())   # решение игры (с распределением дополнительных выплат)
print(cf.check_excess())     # проверка устойчивости относительно коалиций (принадлежность C-ядру)
```

## Описание модулей

### `CoreFinder.py` — основные алгоритмы

Содержит три класса для построения предрешения кооперативной игры, лежащего в C-ядре (если оно непусто).

Игра задаётся числом игроков `n` (или последовательностью их идентификаторов) и характеристической функцией `v` — словарём `{коалиция: выигрыш}`, заданным для всех непустых коалиций.

- **`CoreFinder`** — базовый алгоритм. Последовательно, начиная с коалиций максимального размера, строит предрешение игры так, чтобы минимизировать максимальный эксцесс на каждом шаге.
  - `get_x()` — возвращает предрешение `{игрок: выигрыш}`.
  - `get_imputation(extra_imputation_form=None)` — вычисляет итоговое решение игры, распределяя остаток `v(N) - x(N)` между игроками (по умолчанию равномерно, либо по заданным пропорциям).
  - `check_excess(check="imputation", get_excess=False, print_excesses=False)` — проверяет устойчивость решения относительно всех коалиций и возвращает, принадлежит ли оно C-ядру, а также эксцессы коалиций.
  - Атрибуты: `x` (предрешение), `x_N` (сумма компонент предрешения), `delta_v` (остаток выигрыша `v(N) - x_N`).
- **`CoreFinderOpt(CoreFinder)`** — оптимизированная версия алгоритма. Начинает построение с коалиции всех игроков (Grand coalition) и итеративно перераспределяет выигрыш между игроками, устраняя неустойчивости (положительные эксцессы) коалиций меньшего размера, что существенно ускоряет вычисления на играх с большим числом игроков.
- **`CoreFinderAlt(CoreFinder)`** — альтернативный алгоритм. Итеративно вычисляет минимальные и максимальные поправки к предрешению на основе эксцессов вложенных коалиций и сохраняет лучшее (с минимальной суммой) найденное решение. Поддерживает параметр `early_stop` — досрочную остановку, если найденное решение уже укладывается в `v(N)` (то есть попадает в C-ядро).

Подробное описание параметров, атрибутов и примеры вызовов приведены в docstring класса `CoreFinder` (общий для всех трёх алгоритмов, так как `CoreFinderOpt` и `CoreFinderAlt` наследуют его интерфейс).

### `other_algorithms.py` — вспомогательные алгоритмы

Альтернативные классические решения кооперативных игр, используемые для сравнения с алгоритмами из `CoreFinder.py`.

- **`min_sum_core_point(n, v)`** — точка C-ядра с минимальной суммой компонент, найденная решением задачи линейного программирования (через `scipy.optimize.linprog`) с ограничениями по всем собственным коалициям. Возвращает `None`, если C-ядро пусто.
- **`shapley_value(n, v)`** — вектор Шепли: справедливое распределение выигрыша на основе средневзвешенного маржинального вклада каждого игрока во все возможные коалиции.
- **`nucleolus(v, n, tol=1e-9)`** — N-ядро игры: лексикографическая минимизация вектора эксцессов коалиций при ограничении `sum(x) = v(N)`, вычисляемая последовательностью задач линейного программирования с насыщением коалиций.

Во всех функциях характеристическая функция `v` передаётся как массив `numpy` длиной `2^n`, индексированный битовыми масками коалиций.

### `game_generator.py` — генерация тестовых игр

- **`generate_game(n, superadditive=False, rng=None)`** — генерирует случайную характеристическую функцию для игры из `n` игроков (массив `numpy` длиной `2^n`). При `superadditive=True` функция дополнительно приводится к супераддитивному виду (выигрыш объединения коалиций не меньше суммы выигрышей частей) с помощью вспомогательной функции `_make_superadditive_inplace`, перебирающей все разбиения коалиции на подмножества.

### `test_prepare.py` — подготовка и проведение тестов

Набор функций для массового тестирования и сравнения алгоритмов на сериях случайно сгенерированных игр. Результаты сохраняются на диск в виде `.parquet` и `.xlsx` файлов для последующего анализа в `tests.ipynb`.

- **`pregenerate_games(game_type, n, total, path='local\\results')`** — генерирует серию игр заданного типа (`'Balanced'` или `'Superadditive'`) и числа игроков `n`, для каждой игры заранее вычисляет точку с минимальной суммой ядра (`min_sum_core_point`) и сохраняет игру в `.parquet`.
- **`precompute(game_type, n, total, Shapley=False, CF=False, CFO=False, CFA=False, path='local\\results')`** — прогоняет выбранные алгоритмы (вектор Шепли, `CoreFinder`, `CoreFinderOpt`, `CoreFinderAlt`) на всех сгенерированных играх, замеряет время выполнения и сохраняет решения и метрики в `.xlsx`.
- **`compute(game_type, n, total, coefficient=None, path='local\\results')`** — собирает результаты всех алгоритмов в единую таблицу: время выполнения, отклонение суммы предрешения от `v(N)`, попадание решения в C-ядро и долю попаданий `x_N <= v(N)`.
- **`compute_distance(game_type, n, total, coefficient=None, nucleolus_flag=True, path='local\\results')`** — вычисляет (нормированные) евклидовы расстояния между решениями разных алгоритмов, вектором Шепли и N-ядром для оценки близости найденных предрешений к «эталонному» решению.
- Вспомогательные классы `Excess`, `TCoreFinder`, `TCoreFinderOpt`, `TCoreFinderAlt` — обёртки над основными классами для замера времени выполнения (`dt`) и проверки эксцессов без полного запуска алгоритма.
- **`v_to_dict(v, n)`** — конвертация характеристической функции из массива `numpy` (битовые маски) в словарь `{frozenset(игроки): выигрыш}`, требуемый конструктором `CoreFinder`.

### `tests.ipynb` — тесты и графики

Ноутбук с примерами запуска всех алгоритмов, сравнением их точности и скорости работы на сгенерированных играх разного размера и типа, а также визуализацией результатов (графики времени выполнения, отклонений от ядра, расстояний между решениями).
